## Official SDK & Tools
- [librealsense](https://github.com/IntelRealSense/librealsense) - Official cross‑platform SDK for all Intel RealSense cameras.
- [realsense-viewer](https://github.com/IntelRealSense/librealsense) - Built‑in real‑time visualisation and configuration tool.

- [**librealsense-release**](https://github.com/intel-ros/librealsense-release) - This repository, maintained under the intel-ros organization, hosts the ROS release binaries of the librealsense SDK. It simplifies the installation process for users building robotic systems with Intel RealSense cameras (D400, L500, T265 series) in ROS environments. Target users are roboticists and developers deploying RealSense on ROS-compatible platforms.
