## 官方 SDK 与工具
- [librealsense](https://github.com/IntelRealSense/librealsense) - 适用于所有英特尔 RealSense 摄像头的官方跨平台 SDK。
- [realsense-viewer](https://github.com/IntelRealSense/librealsense) - 内置的实时可视化和配置工具。



- [**librealsense-release**](https://github.com/intel-ros/librealsense-release) - 这是一个Intel RealSense库的官方ROS发布仓库，用于管理librealsense的ROS版本包。该仓库提供预编译的二进制包和元数据，便于在ROS系统（包括ROS1和ROS2）中集成RealSense相机。使用此仓库可以简化D400和L500系列相机的驱动安装和更新过程，适合希望在机器人平台上快速使用RealSense深度相机的ROS开发者。
- [**librealsense-feedstock**](https://github.com/conda-forge/librealsense-feedstock) - Conda-forge的librealsense构建配方仓库，提供跨平台（Linux/macOS/Windows）的librealsense SDK conda包，用户可通过`conda install librealsense`快速安装，无需手动编译，极大简化RealSense开发环境的部署流程。适配Intel官方SDK所有功能模块，面向希望使用Python/C++进行RealSense集成的开发者。
- [**librealsense-tegra-imu**](https://github.com/sigotee754-afk/librealsense-tegra-imu) - 该项目是 librealsense SDK 2.57.6 的补丁版本，专门修复在 Jetson Orin Nano（Tegra 5.15）平台上使用 Intel RealSense D455 相机时 IMU 双管道无法同时读取的问题。通过修改底层驱动代码，确保深度流和 IMU 数据流稳定协同工作，适用于在边缘设备上需要同步 RGB-D 与 IMU 的机器人、SLAM 或姿态估计应用。
- [**buildLibrealsense2TX**](https://github.com/jetsonhacks/buildLibrealsense2TX) - 该项目提供在NVIDIA Jetson TX开发套件上编译Intel RealSense D400系列相机官方库librealsense 2.0的脚本和指南。通过自动化构建流程，解决了Jetson ARM平台上的依赖与交叉编译问题，使用户能在嵌入式设备上快速部署深度感知功能，适用于机器人、边缘计算等场景。
- [**RealSense-Jetson**](https://github.com/ysozkaya/RealSense-Jetson) - 该项目提供在NVIDIA Jetson模块上安装和构建RealSense库的脚本与指南。通过自动化编译librealsense及其依赖，解决Jetson ARM架构下的兼容性问题。适用于在Jetson平台部署D435/D455等RealSense相机的机器人或边缘计算开发者。
- [**realsense_recorder**](https://github.com/Keio-CSG/realsense_recorder) - 一个基于 Python 和 pyrealsense2 的轻量级工具，用于录制 Intel RealSense 相机的深度、彩色和红外流数据。支持实时预览并将帧序列保存为文件，适用于数据采集和实验记录。面向需要快速获取 RealSense 原始传感器数据的开发者。
- [**get3Dcoordinate_fromD435**](https://github.com/yoshi0815/get3Dcoordinate_fromD435) - 该项目提供使用Intel RealSense D435相机获取3D坐标的示例代码，基于Python和pyrealsense2实现。它演示了如何捕获深度图像并计算每个像素的3D坐标，适合需要从D435提取空间信息的开发者。
- [**Tools-of-D435i**](https://github.com/zhuangaoooo/Tools-of-D435i) - 该项目收集了针对 Intel RealSense D435i 相机的实用工具集合，包括深度图像处理、相机标定与数据录制等功能。利用 pyrealsense2 与 librealsense 库实现彩色/深度流同步采集和点云生成，提供可直接运行的 Python 脚本。适合希望快速上手 D435i 进行基础视觉开发的用户。
- [**librealsense-prebuilt**](https://github.com/dirkarnez/librealsense-prebuilt) - 该项目提供 Intel RealSense 官方 SDK librealsense 的预编译版本，用户可直接下载使用，无需从源码构建。它省去编译环境配置的繁琐步骤，支持多种平台和架构，便于快速集成。适合希望直接使用 RealSense 相机 SDK 的开发者。
- [**rs_d455_data_tools**](https://github.com/FengyeXZ/rs_d455_data_tools) - 该Python工具专门用于Intel RealSense D455相机的多模式数据采集，支持同时录制彩色、深度和红外流。基于pyrealsense2实现设备配置与同步，提供命令行接口方便快速启动录制。适用于需要高质量多模态数据的机器人、3D重建或计算机视觉研究者。
- [**IntelRealsenseWebviewer**](https://github.com/aknani1/IntelRealsenseWebviewer) - aknani1/IntelRealsenseWebviewer 是一个基于 Flask 和 Angular 构建的 Web 端查看器，专门用于 Intel RealSense 相机。它模拟官方 RealSense Viewer 的功能，允许用户通过浏览器实时预览深度、彩色和红外流，无需安装桌面版软件。该项目适合需要远程监控或 Web 集成的 RealSense 开发者使用。
- [**realsense-docker**](https://github.com/husarion/realsense-docker) - 该项目提供Docker化的Intel RealSense环境，基于官方librealsense构建容器镜像，可快速部署RealSense SDK及工具，简化依赖管理与跨平台配置。通过Dockerfile封装了必要的运行时库与驱动，确保容器内可直接访问RealSense摄像头。适合需要隔离开发环境或快速部署RealSense应用的开发者。
- [**realsense-recorder-cli**](https://github.com/serene4mr/realsense-recorder-cli) - realsense-recorder-cli 是一个基于 Python 的命令行工具，专用于录制 Intel RealSense 相机（如 D400 系列）的深度、彩色和红外数据流。它通过调用 librealsense SDK 实现实时捕获与存储，方便用户在无图形界面环境下批量采集数据集。适合需要自动化记录 RealSense 传感器数据的机器人或计算机视觉研究人员使用。
- [**Intel-Realsense-Recording-on-Raspberry-Pi-4**](https://github.com/MinHanRyu/Intel-Realsense-Recording-on-Raspberry-Pi-4) - 该项目是一个简单的C++程序，专为在树莓派4上连接Intel Realsense D455相机录制数据而设计。它通过librealsense SDK捕获深度、彩色和红外流，并保存为bag文件或图像序列。适合需要在嵌入式设备（如树莓派）上离线采集RealSense数据的开发者。
- [**D415_Camera**](https://github.com/cqy1218/D415_Camera) - 该项目提供 Intel RealSense D415 深度相机的基础工具集，包含 Python 封装的相机配置、深度流获取与显示等核心功能。直接调用 librealsense SDK 实现图像采集与控制，适用于需要快速使用 D415 进行开发与实验的开发者。
- [**realsense**](https://github.com/WWmore/realsense) - 该项目是一个专为Intel RealSense深度相机设计的Python工具库，提供了API封装和示例程序，直接集成pyrealsense2接口。它支持D435、D455等型号的深度流采集、点云生成和滤波处理，适合需要在Python环境下快速启动RealSense相机开发的工程师和研究人员。
- [**Nvidia_Jetson_Orin_Nano_-_RealSense_D435i_Utilities**](https://github.com/rushabhdhoke/Nvidia_Jetson_Orin_Nano_-_RealSense_D435i_Utilities) - 该项目提供在NVIDIA Jetson Orin Nano平台上控制Intel RealSense D435i相机的实用工具集。主要功能包括RGB-D数据流获取、深度滤波与点云生成，并针对Jetson的ARM架构进行优化。适用于在边缘设备上开发基于RealSense的机器人与计算机视觉应用。
- [**d455_docker**](https://github.com/aakmsk/d455_docker) - 该项目提供了一个针对 Intel RealSense D455 深度相机的 Docker 容器配置，旨在简化开发环境的部署与依赖管理。通过该 Dockerfile，用户可快速搭建包含 librealsense SDK 及其依赖的隔离运行环境，便于在多种 Linux 发行版中复用 RealSense 相关程序。适合需要便携式、可复现 RealSense 开发场景的机器人或计算机视觉工程师。
- [**intelIR2cam**](https://github.com/Gfiles/intelIR2cam) - 该项目通过 Intel RealSense SDK 读取 RealSense 摄像头（如 D400 系列）的红外流，并将其输出为虚拟网络摄像头，便于在其他应用中实时使用红外画面。基于 Python 和 OBS 虚拟摄像头机制实现，适合需要单独利用 RealSense 红外通道进行监控、视觉处理或直播的用户。
- [**realsense-simple-wrapper**](https://github.com/cheneeheng/realsense-simple-wrapper) - 该项目是一个面向 Intel RealSense 相机的简单封装库，提供 Python 和 C++ 接口，简化了相机配置、帧获取及停止流等常用操作。基于 librealsense SDK 实现，目标用户为需要快速集成 RealSense 进行原型开发或学习的开发者。
- [**BuildLibRealSense**](https://github.com/light-tech/BuildLibRealSense) - 该项目提供 GitHub Actions 工作流，用于在 macOS 环境下自动构建 Intel RealSense 官方 SDK（librealsense）的源码。它简化了 macOS 用户编译和安装 librealsense 的过程，无需手动配置依赖和编译参数。适合需要在 macOS 上使用 RealSense 相机（如 D435、D455）的开发者。
- [**librealsense-arm64-build**](https://github.com/bincent0929/librealsense-arm64-build) - 该项目提供了一个Dockerfile，用于在ARM64架构上构建librealsense（Intel RealSense官方SDK），解决ARM64平台（如树莓派、NVIDIA Jetson）上的编译问题。它直接面向RealSense开发者，封装了依赖和构建流程，便于快速部署。适合需要在ARM设备上使用D435/D455等RealSense相机的用户。
- [**simple_application_depth_camera_d455**](https://github.com/leslie9656/simple_application_depth_camera_d455) - 该项目是专为 Intel RealSense D455 深度相机编写的 Python 简单应用示例，演示如何获取和处理深度图像流。尽管仓库无详细描述且星标为零，但项目名称明确指向 D455，可作为初学者快速上手 RealSense 的参考代码。
- [**D455-C468athak**](https://github.com/Avaneesh-Pathak/D455-C468athak) - 该项目仓库名包含“D455”，明确指向 Intel RealSense D455 相机，可能提供与该相机相关的配置、测试或示例代码。作为面向 RealSense 具体型号的 Python 项目，适合需要快速上手 D455 的开发者参考。
- [**realsense_controller**](https://github.com/szzhu-hkclr/realsense_controller) - 该项目是一个基于Python的RealSense相机控制模块，名字直接表明其专为RealSense设备设计。由于缺乏项目描述和文档，具体功能不明确，可能提供流启动、参数调整等基础控制。适合开发者作为探索RealSense编程控制的起点，但需注意项目暂无Star且更新日期异常。

- [**Linemod_ObjectDatasetTools**](https://github.com/duanyhui/Linemod_ObjectDatasetTools) - 该项目提供使用Intel RealSense相机采集并制作Linemod数据集（用于6D物体姿态估计）的工具集。主要功能包括RealSense RGB-D图像采集、标注及格式转换，依赖librealsense SDK。适用于需要快速生成Linemod格式训练数据的计算机视觉研究人员。
- [**realsense-rgbd**](https://github.com/spacedust26/realsense-rgbd) - 该项目是一个基于Python的GUI工具，专为Intel RealSense D435i相机设计，用于同步采集RGB、深度和分割掩码图像，并自动生成YOLO格式标注、存储点云及相机内参。它基于pyrealsense2实现实时数据流捕获，适合需要标注训练数据的机器视觉和机器人开发者。
- [**realsense_d455**](https://github.com/youyongjun/realsense_d455) - 该项目提供Intel RealSense D455相机的校准数据（camera cali data），主要用于相机内参和畸变系数的存储与共享。用户可直接下载这些校准参数，以便在3D重建、视觉SLAM等应用中快速初始化相机模型，避免重复标定。目标用户是使用D455进行计算机视觉研究的开发者和研究人员。
- [**realseanse**](https://github.com/hfarhaditolie/realseanse) - 该项目提供了一个使用Intel RealSense相机收集水下实验数据的完整工具集，包含Python编写的源代码和配套数据集。它专门为水下环境设计，通过RealSense的深度和RGB传感器采集数据，支持研究人员进行水下视觉与深度感知相关实验。适用于需要低成本、易部署的水下数据采集方案的水下机器人或海洋学研究者。
- [**Dynamic-RGB-D-Inertial-Dataset**](https://github.com/charleswangyanan/Dynamic-RGB-D-Inertial-Dataset) - 该数据集使用Intel RealSense D455相机采集，提供高精度运动捕捉设备获得的真实轨迹真值，专门用于动态环境下SLAM算法的评估和开发。数据集包含RGB、深度和惯性测量数据，覆盖多种运动场景，适用于实时视觉-惯性SLAM系统的基准测试。目标用户为SLAM算法研究者及动态环境感知开发者。
